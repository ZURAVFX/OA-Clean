Your files stay on your computer.

OA Clean processes everything locally. Nothing is uploaded to One Agency or a third-party service.

03 / Install

Get up and running.

OA Clean is currently distributed outside the Microsoft and Apple app stores.

  1. 1

    Open the downloaded DMG and drag OA Clean into Applications.

  2. 2

    If macOS says the app is damaged, press Cancel. Do not move it to the Bin.

  3. 3

    Open Terminal, paste the command below and press Return.

xattr -dr com.apple.quarantine "/Applications/OA Clean.app"

Open OA Clean again from Applications. You only need to do this once.

View the illustrated Mac guide ↗
  1. 1

    Open the downloaded Windows installer.

  2. 2

    If Windows shows “Microsoft Defender SmartScreen”, choose More info.

  3. 3

    Choose Run anyway, complete setup and open OA Clean.

The warning appears because the installer is not code-signed. It does not mean the file is damaged.

A clear note

Metadata is only one signal.

OA Clean can remove embedded metadata and normalise common media containers. Platforms use their own changing systems, so no tool can guarantee how a file will be classified or accepted after upload.
